# 사용자에게 하는 말에서 쓰지 않을 표현. 한 줄에 하나.
# `#`로 시작하는 줄과 빈 줄은 무시한다.
#
# **이 목록은 코드가 아니라 데이터다.** 새로운 것이 나오면 여기 한 줄만
# 더하면 된다 — 파이썬을 고치거나 테스트를 다시 짤 필요가 없다.
#
# 왜 종결어미처럼 허용 목록으로 못 하나: 격식체 종결어미는 닫힌 집합이라
# "이걸로 안 끝나면 전부 걸림"이 성립한다. 그런데 비유는 닫히지 않는다 —
# 세상의 모든 사실 서술 동사를 나열할 수 없다. 그래서 여기만 금지 목록이고,
# **새는 것을 전제로** 고치기 쉬운 자리에 뒀다.
#
# 판정은 "사실 서술인가"다. 데이터는 흐르지 않고 들어온다. 화면은 뜨지 않고
# 표시된다. 토큰은 태우는 것이 아니라 쓰는 것이다.

# 뺀 것: `뜨다`(화면이 뜹니다)·`죽다`(서버가 죽었습니다).
# 실측에서 이 둘만으로 전체 턴의 10%가 걸렸는데, 대화에서는 표준 기술
# 한국어다. 사용자가 지적한 자리는 **포트폴리오 문서**였다 — 거기서는
# 문제지만 여기서 전부 막으면 검사가 소음이 되어 결국 꺼진다.
# 문서를 쓸 때 다시 필요하면 이 주석을 지우고 아래 줄을 살리면 된다.
#   뜹니다 / 뜬다 / 뜨고 / 죽습니다 / 죽었
